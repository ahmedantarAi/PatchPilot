# DECISIONS

| ID | Decision | Rationale |
|---|---|---|
| D-01 | Python 3.11 only (`==3.11.*`), uv + `uv.lock`, exact `==` pins | Reproducibility; user requirement |
| D-02 | Ollama native on Windows host, not Docker | User requirement; direct GPU access on RTX 5050 |
| D-03 | Provider interface (`LLMProvider` Protocol) with Ollama, Gemini, Mock | Swappable backends; deterministic CI |
| D-04 | Ollama/Gemini will use `httpx` directly, no vendor SDKs | Fewer pinned dependencies, uniform error handling |
| D-05 | Core services have no compose profile; observability = `profiles: [observability]` | User requirement |
| D-06 | Langfuse **v4** official 6-container topology, images pinned (web/worker 4.72.0, ClickHouse 26.3.62.3, Postgres 17.11-alpine, Redis 7.4.12-alpine). Checked against upstream `docker-compose.yml` on 2026-10-31: no lighter self-hosted topology exists. ClickHouse at 1280 MB and web at 1024 MB are my judgement, not Langfuse-published minimums | Fit budget; upstream advises ≥ 4 GB for the whole stack, so this is tight and unverified under load |
| D-07 | MinIO pinned by digest: `cgr.dev/chainguard/minio@sha256:3b6e40c3…7c82` (image created 2026-10-29). Chainguard's free tier exposes only `:latest`, so a digest is the only exact pin; bump deliberately | Resolved (was: unpinned `:latest`) |
| D-08 | **Supersedes earlier draft.** FastAPI + orchestrator run on the host (`uv run`); Compose runs only Qdrant (core) and Langfuse (observability). Sandbox containers are launched by the host orchestrator via `docker run` with the flags in SPEC §6; no API or sandbox service in Compose | Removes the sandbox-vs-Docker-socket contradiction |
| D-09 | `package = false` in uv; code runs from `src/` via PYTHONPATH | No packaging needed yet |
| D-10 | Ollama default model `qwen2.5-coder:7b` confirmed. Gemini model name lives only in `.env` (`PP_GEMINI_MODEL`, example `gemini-3.8-flash`, checked 2026-10-31); no default in code | User decision (rev 3) |
| D-11 | GitHub Actions pinned to major tags (`@v4`, `@v6`), uv pinned to 0.13.6; accepted for now | User decision (rev 3) |
| D-12 | Qdrant `v1.20.0` as the only core Compose service (512 MB); Compose total 4352 MB | User requirement (rev 2) |
| D-13 | Eval/train pools separated, eval split frozen before any tuning (SPEC §7); sandbox runs sequential and outside the Compose budget (SPEC §8) | User requirement (rev 2) |
| D-14 | Never send private code to the Gemini free tier; enforced in code via request data class (SPEC §9) | User requirement (rev 2) |
| D-15 | Langfuse memory limits accepted as-is, observability stays an optional profile, real usage to be measured later; Langfuse Cloud free tier is the documented fallback (SPEC §5) | User decision (rev 3) |
| D-16 | `host.docker.internal:11434` tested from a container against host Ollama 0.30.7 on Docker Desktop: works with default 127.0.0.1 bind. `OLLAMA_HOST=0.0.0.0` documented only as a fallback with a firewall warning (SPEC §4) | Evidence-based; user request |
| D-17 | Hardened Docker accepted as the v1 sandbox; shared-kernel risk listed as a known limitation (SPEC §6); network-enabled install step that runs no repo code accepted | User decision (rev 3) |
| D-18 | Eval sizes: `seeded_eval` ≥ 100 (plan 120; briefly cut to 40, then restored by user in rev 4), `seeded_train` ≥ 300, `realworld_eval` 20, `findings_eval` 50; real-world/findings repos limited to MIT/Apache-2.0/BSD with license recorded per case | User decision (rev 4) |
| D-19 | `.python-version` (3.11) and a ruff-only `.pre-commit-config.yaml` (ruff-pre-commit v0.17.3, matches pinned ruff); pre-commit is run via `uvx pre-commit@4.7.0`, not added as a dependency | User decision (rev 3) |
| D-20 | `LLMRequest.data_class: Literal["private", "public"] = "private"` (default fails closed; synthetic eval prompts set `"public"`). Phase 1 offline test matrix is `20 passed, 2 deselected` (6×3 shared contract tests + 2 Gemini-specific checks: non-`public` raises `ProviderError`, empty `PP_GEMINI_MODEL` fails fast). Pytest registers the `live` marker and defaults to `-m "not live"` | Pre-Phase 1 design review |
| D-21 | Qdrant is accessed via plain `httpx` REST API (no `qdrant-client` SDK, matching D-04) behind an `Embedder` protocol (`OllamaEmbedder` via `/api/embed` in live mode; deterministic hashed-token `HashEmbedder` in `mock`/CI). Phase 4 tests both Qdrant-up retrieval and Qdrant-down fallback | Pre-Phase 1 design review |
| D-22 | `analyze` runs Python `ast` + `ruff check --isolated --no-config` on the host (never loading target-repo config files) plus LLM diff analysis to emit typed `Finding` objects (`file`, `line`, `category`, `explanation`, `fixable`), shared by `findings_eval` and `propose → verify` | Pre-Phase 1 design review |
| D-23 | `propose` normalizes LLM `SEARCH/REPLACE` blocks (or raw unified diffs) into canonical unified diffs via `difflib.unified_diff`. LangGraph adds a bounded conditional retry edge `verify → propose` with fixed `k = 3` (attempt 1 = `pass@1`, ≤ 3 attempts with test-failure feedback = `pass@3`) | Pre-Phase 1 design review |
| D-24 | Sandbox uses a pure-Python entrypoint in `sandbox/` (no extra `apt-get` packages) to unpack the stdin tar safely, apply the unified diff, run `pytest`, and emit JSON. Single-run lock is a fail-fast cross-process file lock + async lock raising `SandboxBusyError`. Dependency install step populates a named volume (`pip install --only-binary :all: --no-build-isolation --no-input --target /deps`) mounted `:ro` (`PYTHONPATH=/deps`) into the `--network none` run | Pre-Phase 1 design review |
| D-25 | `realworld_eval` (20) and `findings_eval` (50) materialize offline from bundled curated manifests with SPDX license provenance (`MIT`, `Apache-2.0`, `BSD-2-Clause`, `BSD-3-Clause`). `evals verify` runs one fresh `--network none` sandbox container per case (pre-fix and post-fix checks inside it, sequentially, matching SPEC §6) and caches each case's verify result keyed by a hash of the case contents and the sandbox image digest so only changed cases re-run | Pre-Phase 1 design review |
| D-26 | Phase 5 wires `LANGFUSE_INIT_*` headless bootstrap env vars in `docker-compose.yml` and `.env.example` so `obs-up` + `trace-smoke` runs without manual UI setup. Phase 8 exports `seeded_train` as JSONL for a Colab QLoRA notebook (no training deps in `pyproject.toml`), exporting a quantized GGUF + `Modelfile` registered in local Ollama so `evals compare` uses `OllamaProvider` for both runs | Pre-Phase 1 design review |
| D-27 | Phase 1 provider retry & error mapping: `Settings` defines `request_timeout_s=60.0`, `max_attempts=3`, `retry_base_delay_s=0.5`, `retry_max_delay_s=8.0`. Timeouts, transport errors, HTTP 429, and HTTP 5xx retry up to `max_attempts` using `min(max_delay, base * 2^(attempt-1)) * uniform(0.5, 1.0)` (or `Retry-After` seconds/HTTP-date when present); non-429 4xx and malformed responses fail immediately with `ProviderError`. Gemini sends its key via `x-goog-api-key` header (never URL) and redacts `__repr__` | Phase 1 implementation |
| D-28 | `Settings` anchors `.env` loading to the project root (`Path(__file__).resolve().parent.parent.parent / ".env"`) alongside `".env"` with `env_file_encoding="utf-8"`, preventing missing configuration when tests or runners execute from subdirectories or non-root working directories | Phase 1 bugfix |
